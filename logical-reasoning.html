LESSON 01

Number Series

Identify patterns and find the missing number.

What is a Number Series?

A number series is a sequence of numbers arranged according to a specific pattern. In reasoning questions, you need to identify that pattern and find the missing or next number.

💡 Important Idea

Always check the difference between consecutive numbers first. If the difference is not constant, check multiplication, division, squares, cubes or alternate patterns.

Common Patterns

Addition pattern: 2, 4, 6, 8...
Subtraction pattern: 20, 17, 14, 11...
Multiplication pattern: 2, 4, 8, 16...
Square pattern: 1, 4, 9, 16...
Solved Example
Find the next number: 2, 5, 8, 11, ?
Step 1: Find the difference.
5 - 2 = 3
8 - 5 = 3
11 - 8 = 3

Therefore, the pattern is +3.
11 + 3 = 14
Answer: 14
⚡ Exam Shortcut

For number series, first check differences. If differences are changing, check second differences, multiplication/division or alternate terms.
