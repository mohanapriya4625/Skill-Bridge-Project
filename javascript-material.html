LESSON 01

Variables & Data Types

Learn how JavaScript stores and manages data.

What are Variables?

Variables are containers used to store values in JavaScript. Modern JavaScript mainly uses let and const. The older var keyword is also available but is generally avoided in modern code when block scope is preferred.

💡 Key Concept

Use let when the value may change and const when the variable should not be reassigned.

Common Data Types

String – text values such as "SkillBridge"
Number – numeric values such as 100
Boolean – true or false
Object – collection of related properties
JavaScript Example 
const studentName = "Mohana";
let score = 85;
const passed = true;

console.log(studentName);
console.log(score);
console.log(passed);
Output:
Mohana
85
true
⚡ Developer Tip

Prefer const by default. Use let only when you know the variable needs to be reassigned. This makes your code easier to understand and maintain.
